## 怎么用

- **想复习**：进课程页，按 Lecture 顺序看讲义；考前先看「期中复习」，再回讲义补细节。
- **想练习**：进课程的「练习」，选基础卷或进阶卷，直接在页面里作答（进度会存在浏览器本地）；交卷后点「查看解析」对答案。
- **想打印**：练习页里有「打印版题干」，解析和讲义都可以直接 Ctrl+P。
